# security

Security: users, roles and what each role may do with entities, forms and lists. Needs the data model, the forms and the lists

A metamodel of [LINEA](https://github.com/lbdudc/linea) (`security` v1.0.0). Its grammars, specs and templates are in this folder; LINEA reads them from its registry (see the [repository README](../../README.md)).
