# lists

Lists: tables of data-model entities, with the columns to show and how to sort them. Optional in a product; needs the data model

A metamodel of [LINEA](https://github.com/lbdudc/linea) (`lists` v1.0.0). Its grammars, specs and templates are in this folder; LINEA reads them from its registry (see the [repository README](../../README.md)).
